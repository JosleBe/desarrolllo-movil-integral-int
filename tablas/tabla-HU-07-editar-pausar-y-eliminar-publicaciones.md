# Tabla técnica — HU-07-editar-pausar-y-eliminar-publicaciones

> Matriz de validación funcional y técnica.

| **Campo** | **Detalle** |
|:---|:---|
| **Historia de usuario** | **HU-07: Editar, pausar y eliminar publicaciones** |
| **¿Qué comprueba?** | El propietario puede editar, pausar y reactivar; una publicación pausada deja de ser rentable; no se elimina si tiene rentas activas o pendientes y otro usuario no puede modificarla. |
| **Tipo de prueba** | Interfaz, unitaria e integración |
| **Criterio de aprobación** | Se respetan propiedad y estados: pausar oculta la oferta, eliminar con renta se rechaza con explicación y solo el Vendedor dueño puede cambiarla. |
